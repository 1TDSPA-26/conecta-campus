# Conecta Campus v0.5

Código de referência da evolução trabalhada na Apostila 05.

## O que esta versão apresenta

- cinco páginas HTML conectadas por caminhos relativos;
- página de integrantes;
- formulário de contato acessível;
- CSS externo com `@media`, sem Flexbox e sem Grid;
- JavaScript externo com validação inicial de campos;
- mensagens de erro próximas dos campos e mensagem geral de status.

## Como executar

Abra `index.html` no navegador e navegue pelos links do menu. Para testar o JavaScript, abra `contato.html`, tente enviar o formulário vazio e depois preencha dados válidos.

## Observação

O formulário apenas valida os campos no navegador. Ele não envia informações para servidor, banco de dados ou e-mail.
